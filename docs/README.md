# `docs/`

**Why this folder exists:** to hold the artifacts that back up claims made in
the READMEs — reference outputs the test suite checks against, and generated
figures — so those claims are checkable rather than asserted.

| path | what it is |
|---|---|
| `tf_reference/` | ground-truth renders from the **original TensorFlow graph** |
| `images/` | figures generated by `scripts/plot_history.py` |

## `tf_reference/`

Nine PNGs: the `R`, `I_delta` and `S` outputs of the authors' released
TensorFlow implementation on LOL eval images 1, 22 and 55, produced by
running their model with their published weights.

`scripts/verify_port.py` checks this repository's PyTorch model against them.
It is what turns "faithful reimplementation" from a claim into a test — see
[`../scripts/README.md`](../scripts/README.md).

Stored as 8-bit PNGs rather than raw float tensors to keep the repository
small. That caps the achievable precision at one 8-bit level, which is far
tighter than any architectural error would survive; the float32 comparison
run when these were generated agreed to **1.4e-05**.

Regenerating them requires TensorFlow, which is not a dependency of this
project — see the docstring of `scripts/convert_tf_weights.py` for the
two-environment procedure.
